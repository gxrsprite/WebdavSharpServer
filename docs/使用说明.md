# WebdavSharpServer 使用说明（Windows x64 发布包）

## 1. 这是什么

WebdavSharpServer：基于 .NET 10 的跨平台文件服务，一套用户/权限配置同时提供
**WebDAV + FTP + SMB** 三种协议，自带网页管理后台。

| 入口     | 默认地址                          | 账号            |
|----------|-----------------------------------|-----------------|
| WebDAV   | `http://本机IP:5210/dav/`          | `admin / admin` |
| 管理后台 | `http://本机IP:5210/admin`         | `admin / admin` |
| FTP      | 默认关闭，开后 `本机IP:2121`       | 同上            |
| SMB      | 按管理后台「服务」页配置（默认 5000） | 同上          |

> 首次登录管理后台后，请立刻改掉 `admin` 密码（`用户` 页 → 重置密码）。

## 2. 环境要求：必须安装 .NET 10

本发布包是 **framework-dependent（框架依赖型）**：包里只有程序本身，
**不含 .NET 运行时**，所以运行前必须先装微软官方的 **.NET 10 运行时**。
装一次即可，体积小、后续升级 .NET 安全补丁不用重新下载本软件。

- 要装的包名：**ASP.NET Core 运行时 10.x（Windows x64）**
  （它已包含 .NET 运行时 + Web 服务运行所需组件，装这一个就够了）
- 官方下载地址：<https://dotnet.microsoft.com/download/dotnet/10.0>
  打开页面 → 右侧找到 **ASP.NET Core Runtime 10.x.x** → 下载 **x64 Installer** → 一路下一步安装。
- 装完验证（PowerShell 里执行，能看到 `Microsoft.AspNetCore.App 10.x` 即成功）：
  ```powershell
  dotnet --list-runtimes
  ```
- 发布包共 4 个（均为 framework-dependent，都要装对应平台的 .NET 10）：
  `win-x64` / `win-arm64` / `linux-x64` / `linux-arm64`。
  macOS、Linux-musl（Alpine）、win-x86 等**没有**内置 SQLite 原生库，
  需用源码自编或切 PostgreSQL/MySQL。

> 不想装运行时？可以自行用源码编 self-contained（自包含）版：
> `dotnet publish -c Release -r win-x64 --self-contained true`
> （包大 ~60MB，但双击即跑，见本仓库 `scripts/publish-webdavsharp.ps1`）。

## 3. 运行步骤

1. 解压 `WebdavSharpServer-win-x64-*.zip` 到任意目录（路径不要带中文和空格，
   例如 `D:\WebdavSharpServer`）；
2. 双击 `WebdavSharp.Server.exe`（黑窗口不要关，关掉即停服；
   想开机自启/后台跑，请用 NSSM 或注册为 Windows 服务，见 §6）；
3. 浏览器打开 `http://127.0.0.1:5210/admin`，`admin / admin` 登录，
   先改密码，再按需添加用户、挂载目录、访问规则；
4. 客户端连接 `http://你的IP:5210/dav/` 即可存取文件；
5. 数据保存在程序目录下的 `LocalPaths/`：
   `LocalPaths/dav-root/` 是文件根，`LocalPaths/webdavsharp.db` 是数据库。
   **备份这整个目录即可迁移**。

### Linux 平台（linux-x64 / linux-arm64 包）

1. 先装对应平台的 ASP.NET Core 运行时 10.x（同 §2 下载页，选 Linux 包）；
2. 解压后：
   ```bash
   chmod +x WebdavSharp.Server
   ./WebdavSharp.Server
   ```
   （必须 `cd` 到解压目录再启动；后台跑可用 `systemd`，`WorkingDirectory` 指到该目录）；
3. 其余与 Windows 一致：`http://IP:5210/admin`，`admin / admin`，先改密码。

## 4. 改端口 / 改配置

- 改 Web 端口：用记事本打开 `appsettings.json`，改 `Dav:Port`
  （或设环境变量 `Dav__Port=6065`，环境变量优先）；
- 开 FTP：管理后台「服务」页打开，或 `appsettings.json` 里
  `"FtpEnabled": true`（端口 `FtpPort`，默认 2121）；
- SMB 端口/开关：管理后台「服务」页（标准 445 需管理员权限且勿与系统共享冲突，
  局域网联调可用 5000 等自定义端口）；
- 生产环境模板见源码 `appsettings.Production.example.json`，
  密钥建议用 `appsettings.local.json` 或环境变量覆盖（该文件不会被打包上传）。

## 5. 客户端速查（均已实测）

- Windows 资源管理器：映射网络驱动器填 `http://IP:5210/dav/`
  （需先 `BasicAuthLevel=2`，详见 `docs/client-compat.md`）；SMB/FTP 直连亦可；
- 安卓：CX 文件管理器（SMB）、MT管理器 / ES文件管理器（SMB / WebDAV / FTP 均可）；
- Windows MiniRedir（`net use`）、rclone 等见 `docs/client-compat.md` 兼容矩阵。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 双击闪退 / 提示缺 `framework Microsoft.AspNetCore.App` | 没装 .NET 10（回 §2 安装） |
| 端口被占用启动失败 | 改 `Dav:Port`，或关掉占用 5210 的程序 |
| 局域网别人连不上 | Windows 防火墙放行 5210（及 FTP/SMB 端口）；确认监听地址是 `0.0.0.0` |
| 忘记 admin 密码 | 删 `LocalPaths/webdavsharp.db` 重启（会恢复种子账号，**数据表清空前先备份**） |
| 想后台运行 | NSSM（`nssm install WebdavSharpServer`）或 `sc.exe create` 注册服务 |
